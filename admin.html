Importer un nouveau PDF ?

Fonctionnalité non fiable automatiquement : l'extraction FR/WO en 2 colonnes mélange l'ordre. Procédure recommandée : extrayez le texte (script tools/extract.py à venir), relisez, puis importez via Import JSON au format {id,cat,p,qfr,afr,qwo,awo,qar,aar,r}. Les collections futures : ajoutez une clé collection par carte.
